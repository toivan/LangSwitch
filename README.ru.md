# LangSwitch

[English](README.md) · [Русский](README.ru.md)

Небольшое приложение для строки меню macOS, которое переключает включённые языки клавиатуры (источники ввода) коротким нажатием **Fn/🌐**. Источники переключаются напрямую, без собственного всплывающего окна выбора языка.

Этот [форк toivan/LangSwitch](https://github.com/toivan/LangSwitch) основан на [оригинальном проекте LangSwitch](https://github.com/Nikeev/LangSwitch), начатом Nikeev, и содержит изменения для версии 2.0.0.

## Преимущества и приватность

- **Быстрое переключение:** короткое нажатие Fn/🌐 выбирает следующий включённый источник ввода.
- **Без записи букв и паролей:** LangSwitch обрабатывает изменения состояния клавиш-модификаторов, чтобы распознавать нажатия Fn/🌐. Приложение не подписывается на обычные события нажатия клавиш и не собирает вводимый текст.
- **Без истории действий и переключений:** приложение не сохраняет историю нажатий, действий или успешных смен источника ввода.
- **Без телеметрии:** нет аналитики, отчётов об использовании и фоновых сетевых запросов.
- **Работает офлайн:** для переключения источников ввода не нужны интернет и учётная запись.
- **Автозапуск под вашим контролем:** запуск при входе в систему включается по желанию и меняется через меню.

Сетевые обращения связаны с явными действиями пользователя: **Check for Updates** отправляет HTTPS-запрос к GitHub releases API, а **GitHub Page** открывает репозиторий в браузере. Общие диагностические сообщения об ошибках могут выводиться; успешные переключения источников ввода не записываются в лог.

## Начало работы

DMG релиза содержит универсальное приложение для Apple Silicon (arm64) и Intel (x86_64), которому нужна macOS 12 или новее. Приложение имеет **ad-hoc подпись**: подписи Developer ID и нотарификации Apple нет. macOS может заблокировать первый запуск.

1. Скачайте DMG LangSwitch со [страницы релизов](https://github.com/toivan/LangSwitch/releases).
2. Откройте DMG и перетащите LangSwitch в папку «Программы».
3. В настройках клавиатуры macOS отключите встроенное действие клавиши Fn/🌐, чтобы каждое нажатие обрабатывалось один раз.
4. Откройте LangSwitch из папки «Программы». В строке меню появится значок глобуса.
5. Коротко нажимайте Fn/🌐 для переключения между включёнными источниками ввода.

Если macOS блокирует LangSwitch из-за неподтверждённого разработчика или отсутствия нотарификации, продолжайте только если доверяете скачанному релизу. После заблокированной попытки выберите для LangSwitch **Open Anyway** («Всё равно открыть») в настройках безопасности macOS, затем подтвердите **Open** («Открыть»), следуя [инструкции Apple](https://support.apple.com/en-us/102445). Исключение создаётся для этого приложения; Gatekeeper остаётся включённым.

Доступ к глобальным событиям клавиатуры контролирует macOS. Если нажатия Fn/🌐 не работают, проверьте разрешение LangSwitch в разделе «Универсальный доступ» настроек конфиденциальности macOS.

## Управление через меню

**Launch at Login** доступен начиная с macOS 13. При новой установке автозапуск выключен. Регистрации автозапуска из прежних версий сохраняются, отражаются в меню и могут быть отключены через него.

Если требуется одобрение macOS, пункт **Login Items Settings…** открывает соответствующие системные настройки. Тире возле **Launch at Login** означает ожидание одобрения; нажатие на этот пункт отменяет регистрацию.

**Hide Icon** скрывает глобус только в текущей сессии. Чтобы сразу вернуть значок, снова откройте LangSwitch из Finder или Spotlight. Он также появляется при следующем запуске приложения, в том числе после обновления с прежней версии, которая запоминала скрытое состояние.

Окно **About LangSwitch** содержит кнопку **GitHub Page** и ручную проверку **Check for Updates**. Перед выводом результата проверяются HTTP-ответ и версия релиза. Проверка не скачивает и не устанавливает обновления.

Сообщения проверки обновлений различают недоступность информации о публичном релизе (HTTP 404), сетевые ошибки, ограничения запросов или отказ в доступе и другие ошибки HTTP. Если информация о публичном релизе недоступна, сообщение указывает на страницу релизов форка.

**Exit** завершает приложение. Если автозапуск включён, выход его не отключает; для изменения этой настройки используйте **Launch at Login**.

## Требования

- macOS 12 или новее; управление автозапуском требует macOS 13 или новее.
- Для разработки: Xcode с компилятором Swift 6 и совместимым macOS SDK.
- Для запуска модульных тестов нужна macOS 14 или новее. Это требование относится к тестовой цели; само приложение поддерживает macOS 12.
- Сторонних пакетов нет. Приложение использует AppKit, SwiftUI, Carbon, Foundation и ServiceManagement из Apple SDK.

## Сборка и тестирование

Откройте `LangSwitch.xcodeproj` в Xcode. Для подписанной сборки выберите свою команду разработчика.

Для сборки без подписи и запуска тестов логики:

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -project LangSwitch.xcodeproj -scheme LangSwitch \
  -configuration Release -derivedDataPath /tmp/LangSwitch-DerivedData \
  CODE_SIGNING_ALLOWED=NO build

DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -project LangSwitch.xcodeproj -scheme LangSwitch \
  -destination 'platform=macOS' -derivedDataPath /tmp/LangSwitch-DerivedData \
  CODE_SIGNING_ALLOWED=NO test
```

Если Xcode установлен в другом месте, измените `DEVELOPER_DIR`. Переменная задаётся для отдельной команды и позволяет использовать Xcode, даже когда `xcode-select` указывает на Command Line Tools, без изменения общесистемного каталога инструментов разработчика.

Модульные тесты проверяют сравнение версий без запуска приложения. Они охватывают числовые компоненты, префиксы `v`/`V`, порядок предварительных версий, метаданные сборки, некорректные теги и числа, которые не помещаются в машинный целочисленный тип.

Проверено с Xcode 27.0 (27A266a), Swift 6.4 и macOS 27 SDK: сборка Release 2.0.0 (build 10) без подписи успешно выполнена для arm64 и x86_64, все 8 методов модульных тестов прошли.

Автоматические проверки охватывают компиляцию и логику сравнения версий; они не проверяют интерфейс приложения и взаимодействие с настройками автозапуска. Для собственной сборки с Developer ID настройте свою подпись и отправьте сборку на нотарификацию через Xcode.

Изменения этой версии описаны в [заметках к релизу 2.0.0](RELEASE_NOTES.ru.md); также доступна [английская версия](RELEASE_NOTES.md).
